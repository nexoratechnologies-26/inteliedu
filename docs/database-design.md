# Inteliedu - Preliminary Database Design

## 1. Overview
This document outlines the preliminary relational schema design for the Inteliedu platform on PostgreSQL (managed via Supabase). It incorporates support for vector embeddings (`pgvector`), granular Row-Level Security (RLS), and real-time pub/sub subscriptions.

> **Note**: This is an architectural design document. Physical migrations and database scripts will be provisioned by Nidiya during database initialization.

---

## 2. Entity-Relationship Diagram (Logical)

```
 [roles] ──< [users] ──< [profiles]
                │
                ├──< [class_members] >── [classes]
                │                           │
                │                           └──< [courses] ──< [lessons]
                │                                                  ├──< [learning_materials]
                │                                                  └──< [three_d_models]
                │
                ├──< [quiz_attempts] >── [quizzes] ──< [questions]
                │
                ├──< [submissions]   >── [assignments]
                │

                │
                ├──< [ai_conversations] ──< [ai_messages]
                │
                └──< [student_progress] >── [lessons]
```

## 3. Entity Definitions & Schema Specifications

### 1. `roles`
Defines system access roles.
- `id`: VARCHAR(32) PRIMARY KEY (`admin`, `teacher`, `student`)
- `description`: TEXT
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 2. `users`
Maps directly to `auth.users` in Supabase.
- `id`: UUID PRIMARY KEY REFERENCES auth.users(id)
- `email`: VARCHAR(255) UNIQUE NOT NULL
- `role_id`: VARCHAR(32) REFERENCES roles(id) NOT NULL DEFAULT 'student'
- `created_at`: TIMESTAMPTZ DEFAULT now()
- `updated_at`: TIMESTAMPTZ DEFAULT now()

### 3. `profiles`
Extended profile information for all users.
- `id`: UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE
- `full_name`: VARCHAR(255) NOT NULL
- `avatar_url`: TEXT
- `bio`: TEXT
- `grade_level`: VARCHAR(64) (e.g., 'Grade 10', 'Undergraduate')
- `created_at`: TIMESTAMPTZ DEFAULT now()
- `updated_at`: TIMESTAMPTZ DEFAULT now()

### 4. `classes`
Classroom or cohort groups managed by teachers.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `name`: VARCHAR(255) NOT NULL
- `code`: VARCHAR(32) UNIQUE NOT NULL (e.g., class join code)
- `description`: TEXT
- `teacher_id`: UUID REFERENCES users(id) ON DELETE RESTRICT
- `academic_year`: VARCHAR(32)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 5. `class_members`
Association between students and classes.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `class_id`: UUID REFERENCES classes(id) ON DELETE CASCADE
- `student_id`: UUID REFERENCES users(id) ON DELETE CASCADE
- `enrolled_at`: TIMESTAMPTZ DEFAULT now()
- `status`: VARCHAR(32) DEFAULT 'active' (e.g., `active`, `archived`)
- UNIQUE(`class_id`, `student_id`)

### 6. `courses`
Curriculum courses associated with classes or open catalogs.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `class_id`: UUID REFERENCES classes(id) ON DELETE CASCADE
- `title`: VARCHAR(255) NOT NULL
- `description`: TEXT
- `subject`: VARCHAR(128) (e.g., 'Physics', 'Biology', 'Robotics')
- `created_by`: UUID REFERENCES users(id)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 7. `lessons`
Individual units/modules within a course.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `course_id`: UUID REFERENCES courses(id) ON DELETE CASCADE
- `title`: VARCHAR(255) NOT NULL
- `content`: TEXT (Markdown or structured HTML)
- `order_index`: INTEGER NOT NULL DEFAULT 0
- `duration_minutes`: INTEGER DEFAULT 45
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 8. `learning_materials`
Uploaded documents, references, and vector embeddings for RAG.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `lesson_id`: UUID REFERENCES lessons(id) ON DELETE CASCADE
- `title`: VARCHAR(255) NOT NULL
- `file_type`: VARCHAR(32) (e.g., `pdf`, `docx`, `video_url`, `notes`)
- `storage_path`: TEXT NOT NULL (path inside Supabase Storage)
- `content_text`: TEXT (extracted text for parsing)
- `embedding`: vector(1536) (pgvector column for semantic search)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 9. `three_d_models`
Catalog of interactive 3D assets linked to lessons.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `lesson_id`: UUID REFERENCES lessons(id) ON DELETE SET NULL
- `name`: VARCHAR(255) NOT NULL
- `category`: VARCHAR(64) NOT NULL (`solar-system`, `human-anatomy`, `engineering`)
- `model_url`: TEXT NOT NULL (GLB/GLTF file URL in Supabase Storage)
- `thumbnail_url`: TEXT
- `metadata`: JSONB (camera defaults, annotations, explosion axes)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 10. `quizzes`
Assessment definitions created manually or generated by AI.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `lesson_id`: UUID REFERENCES lessons(id) ON DELETE CASCADE
- `title`: VARCHAR(255) NOT NULL
- `description`: TEXT
- `is_ai_generated`: BOOLEAN DEFAULT false
- `time_limit_minutes`: INTEGER DEFAULT 15
- `passing_score`: INTEGER DEFAULT 70
- `created_by`: UUID REFERENCES users(id)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 11. `questions`
Individual questions belonging to a quiz.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `quiz_id`: UUID REFERENCES quizzes(id) ON DELETE CASCADE
- `question_text`: TEXT NOT NULL
- `question_type`: VARCHAR(32) NOT NULL (`multiple_choice`, `true_false`, `3d_hotspot`)
- `options`: JSONB NOT NULL (Array of choices or hotspot identifiers)
- `correct_answer`: TEXT NOT NULL
- `explanation`: TEXT
- `points`: INTEGER DEFAULT 1
- `order_index`: INTEGER DEFAULT 0

### 12. `quiz_attempts`
Student submissions and grading records for quizzes.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `quiz_id`: UUID REFERENCES quizzes(id) ON DELETE CASCADE
- `student_id`: UUID REFERENCES users(id) ON DELETE CASCADE
- `score`: NUMERIC(5,2) NOT NULL
- `total_points`: INTEGER NOT NULL
- `answers`: JSONB NOT NULL (Recorded student answers)
- `ai_feedback`: TEXT
- `submitted_at`: TIMESTAMPTZ DEFAULT now()

### 13. `assignments`
Coursework assignments and homework tasks.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `lesson_id`: UUID REFERENCES lessons(id) ON DELETE CASCADE
- `title`: VARCHAR(255) NOT NULL
- `instructions`: TEXT NOT NULL
- `due_date`: TIMESTAMPTZ NOT NULL
- `max_score`: INTEGER DEFAULT 100
- `created_by`: UUID REFERENCES users(id)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 14. `submissions`
Student submissions for assignments.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `assignment_id`: UUID REFERENCES assignments(id) ON DELETE CASCADE
- `student_id`: UUID REFERENCES users(id) ON DELETE CASCADE
- `content`: TEXT
- `attachment_path`: TEXT (Supabase Storage file link)
- `grade`: NUMERIC(5,2)
- `feedback`: TEXT
- `graded_by`: UUID REFERENCES users(id)
- `submitted_at`: TIMESTAMPTZ DEFAULT now()
- `graded_at`: TIMESTAMPTZ

### 15. `attendance`
Session attendance records for live classrooms.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `class_id`: UUID REFERENCES classes(id) ON DELETE CASCADE
- `student_id`: UUID REFERENCES users(id) ON DELETE CASCADE
- `session_date`: DATE NOT NULL DEFAULT CURRENT_DATE
- `status`: VARCHAR(32) NOT NULL (`present`, `absent`, `late`, `excused`)
- `join_time`: TIMESTAMPTZ
- `leave_time`: TIMESTAMPTZ
- `duration_seconds`: INTEGER DEFAULT 0
- UNIQUE(`class_id`, `student_id`, `session_date`)

### 16. `ai_conversations`
Chat sessions between a student and the AI tutor.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `student_id`: UUID REFERENCES users(id) ON DELETE CASCADE
- `lesson_id`: UUID REFERENCES lessons(id) ON DELETE CASCADE
- `title`: VARCHAR(255) DEFAULT 'New AI Session'
- `created_at`: TIMESTAMPTZ DEFAULT now()
- `updated_at`: TIMESTAMPTZ DEFAULT now()

### 17. `ai_messages`
Individual message turns inside an AI conversation.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `conversation_id`: UUID REFERENCES ai_conversations(id) ON DELETE CASCADE
- `sender_type`: VARCHAR(16) NOT NULL (`user`, `assistant`, `system`)
- `content`: TEXT NOT NULL
- `citations`: JSONB (Referenced document IDs / chunks)
- `created_at`: TIMESTAMPTZ DEFAULT now()

### 18. `student_progress`
Granular lesson completion and topic mastery tracking.
- `id`: UUID PRIMARY KEY DEFAULT gen_random_uuid()
- `student_id`: UUID REFERENCES users(id) ON DELETE CASCADE
- `lesson_id`: UUID REFERENCES lessons(id) ON DELETE CASCADE
- `status`: VARCHAR(32) DEFAULT 'not_started' (`not_started`, `in_progress`, `completed`)
- `time_spent_seconds`: INTEGER DEFAULT 0
- `last_accessed_at`: TIMESTAMPTZ DEFAULT now()
- UNIQUE(`student_id`, `lesson_id`)

## 4. Security & Row-Level Security (RLS) Strategy
1. **Students**: Read access to classes/courses/lessons they are enrolled in; read/write access to their own quiz attempts, assignments, AI conversations, and progress.
2. **Teachers**: Full read/write access to courses, classes, materials, quizzes, and assignments they manage; read/grade access to student attempts in their classes.
3. **Admins**: Full platform-wide administrative read/write access across all tables.
